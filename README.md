# 🍽️ 清华食堂 — THU Canteen

> 一个清华同学为自己（和全校 3 万干饭人）打造的食堂信息查询与评价小程序

**再也不用在 16 个食堂、几百个窗口之间迷茫了！** 搜"生煎包"就能看到哪些窗口有卖、多少钱、支持微信还是只能刷校园卡、同学们怎么评价。还能分析一顿饭的营养成分，导入校园卡消费记录自动生成饮食日记。

---

## ✨ 能做什么

| 功能 | 说明 |
|------|------|
| 🔍 **搜菜品** | 搜"生煎包"→ 清芬园 ¥3/个 + 桃李园 ¥3.5/个，支持中文分词+jieba |
| 🏫 **逛食堂** | 17 个食堂、80+ 窗口、270+ 菜品，楼层分布、营业时间一目了然 |
| 💳 **看支付方式** | 标注每个窗口是校园卡 / 微信 / 支付宝，不用到了窗口才发现刷不了 |
| 📊 **营养分析** | 选几道菜，自动算总热量、蛋白质、碳水的每日摄入占比 |
| ⭐ **评价打分** | 给窗口和菜品打分、写评价、打标签（"分量足""排队快"） |
| 📝 **饮食日记** | 从 card.tsinghua.edu.cn 导出校园卡消费 CSV，一键导入，自动统计每月在哪个食堂花了多少钱 |
| 🛠️ **管理后台** | Web 界面增删改查数据，Excel 批量导入菜品，志愿者也能帮忙维护 |

## 🏗️ 技术栈

```
📱 微信小程序（原生）    ← 用户端
🎛️ Vue 3 + Element Plus  ← 管理后台
🖥️ FastAPI + SQLite      ← 后端 API
🔍 jieba + FTS5          ← 中文全文搜索
```

## 🚀 快速开始

### 1. 后端

```bash
cd backend
conda create -n thucanteen python=3.11
conda activate thucanteen
pip install -r requirements.txt

# 写入清华大学食堂数据（6 个学生食堂 + 教工食堂 + 特色餐厅）
set PYTHONUTF8=1
python seed_data.py

# 启动
python -m uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
```

浏览器打开 http://localhost:8000/api/docs 查看所有 API。

### 2. 管理后台

```bash
cd admin
npm install
npm run dev
```

打开 http://localhost:3000，默认账号 `admin_seed` 密码 `admin123`。

### 3. 微信小程序

1. 下载[微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. 导入 `miniprogram/` 目录
3. 右上角「详情」→「本地设置」→ 勾选「不校验合法域名」
4. 预览

## 🧪 数据来源

种子数据基于 **2023-2026 年清华官方公众号、新生攻略、校园媒体报道** 整理：
- 紫荆园（5 层，14 个窗口）—— 炸鲜奶、涮羊肉 20 元、6 元两荤一素套餐
- 清芬园（4 层）—— **生煎包 3 元/个**、北京烤鸭 9 元/盘、🆕 江西小炒（2026 年新开）
- 桃李园（4 层）—— **夜宵 21:00-23:00**（唯一稳定夜宵）、冒烤鸭、烧鸟丼
- 听涛园（面食天堂）—— 油泼面、肉夹馍 3 元/个、水饺 1.4 元/两
- 丁香园（肠粉早八排队王）、观畴园（万人食堂）、芝兰园（小火锅）
- 双清园（2023 年新开）、融园（金融学院）、熙春园（桌餐宴请）
- 覆盖全部 10 个学生食堂 + 5 个教工食堂 + 2 个特色餐厅

> ⚠️ 食堂窗口和菜品会随季节变化。我们设计了众包更新机制（管理后台 + Excel 批量导入），欢迎志愿者帮忙维护！

## 🤝 如何贡献数据

食堂信息经常变，一个人的力量不够。你可以：

1. **直接改**：登录管理后台，增删改窗口/菜品
2. **批量传**：整理 Excel 表格，导入管理后台
3. **提 issue**：在 GitHub 告诉我们哪个窗口变了一起来维护清华干饭人的共同财产 💪
